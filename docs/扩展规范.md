# 桌面看板 扩展规范 v1

这份规范说明怎样用 **JSON** 给「桌面看板」批量导入数据、以及制作自定义小组件。
写给人看，也写给 AI 看：把整份文档交给任意 AI（ChatGPT、Claude、DeepSeek、GLM……），再描述你的需求，让它按规范输出 JSON，然后粘贴到看板的「创造台」即可。

**给 AI 的总要求**

- 只输出一个 JSON 对象，不要输出解释文字；需要说明时写进 JSON 字段里。
- 不要编造 `id`、创建时间等内部字段，程序会自动生成。
- 日期统一用 `YYYY-MM-DD`，时间用 24 小时制 `HH:mm`，都是本地时间。
- 不认识的字段会被忽略；缺省的可选字段用默认值。

## 一、数据导入 `deskboard.import/v1`

一次可以导入项目、待办、日程、备忘录和资讯源中的任意几类。

```json
{
  "format": "deskboard.import/v1",
  "projects": [],
  "tasks": [],
  "events": [],
  "notes": [],
  "feeds": []
}
```

### 1. 项目 `projects[]`

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `name` | string | 是 | 项目名称。与已有项目同名时按「合并」处理（见下文） |
| `emoji` | string | 否 | 一个 emoji 作为图标，默认随机 |
| `color` | string | 否 | `#RRGGBB`，默认蓝色 |
| `status` | string | 否 | `active` 进行中（默认）/ `paused` 暂停 / `done` 已结束 |
| `overview` | string | 否 | 项目概况，Markdown。建议包含目标、背景、关键节点、相关链接 |
| `items` | array | 否 | 看板条目，见下表 |
| `logs` | array | 否 | 工作日志，见下表 |

`items[]`：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `text` | string | 是 | 一句话描述这一项，尽量以动词开头，20 字以内 |
| `status` | string | 否 | `todo` 待办（默认）/ `doing` 进行中 / `done` 已完成 |
| `detail` | string | 否 | 细节说明 |
| `due` | string | 否 | 截止日期 `YYYY-MM-DD` |

`logs[]`：`{ "date": "YYYY-MM-DD", "text": "当天做了什么" }`

**整理建议**：把一段原始材料整理成项目时，概况写「是什么、为什么、做到什么程度算完成」；条目按可执行的最小单位拆分；已经完成的事放进 `done`，正在做的放 `doing`；有明确日期的进展写进 `logs`。

### 2. 待办 `tasks[]`

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `title` | string | 是 | 待办内容 |
| `due` | string | 否 | 截止日期 `YYYY-MM-DD` |
| `priority` | number | 否 | `0` 普通（默认）/ `1` 重要 / `2` 紧急 |
| `done` | boolean | 否 | 是否已完成，默认 `false` |
| `project` | string | 否 | 关联的项目名称 |

### 3. 日程 `events[]`

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `title` | string | 是 | 日程标题 |
| `date` | string | 是 | `YYYY-MM-DD` |
| `start` / `end` | string | 否 | `HH:mm`；不填 `start` 表示全天 |
| `remind` | number | 否 | 提前几分钟提醒，`0` 为开始时提醒；不填不提醒 |
| `color` | string | 否 | `#RRGGBB` |
| `notes` | string | 否 | 备注 |
| `project` | string | 否 | 关联的项目名称 |

### 4. 备忘录 `notes[]`

`{ "title": "标题", "content": "Markdown 正文", "pinned": false }`

### 5. 资讯源 `feeds[]`

`{ "name": "显示名称", "url": "RSS 或 Atom 地址" }`

只支持 RSS / Atom。常见地址形如 `/feed`、`/rss`、`/feed.xml`、`/atom.xml`。与已有资讯源地址相同的会跳过。

### 合并规则

| 类型 | 判断重复 | 处理 |
|---|---|---|
| 项目 | 名称相同 | 默认合并：追加新条目（`text` 相同的跳过）和新日志；原概况为空时才写入新概况。导入界面里也可以选择「另建一个同名项目」 |
| 待办 | 标题和截止日期都相同 | 跳过 |
| 日程 | 标题、日期、开始时间都相同 | 跳过 |
| 备忘录 | 标题相同 | 跳过 |
| 资讯源 | 地址相同 | 跳过 |

导入前会显示预览，确认后才写入；导入前自动备份，可以一键撤销。

### 示例

```json
{
  "format": "deskboard.import/v1",
  "projects": [
    {
      "name": "个人博客改版",
      "emoji": "📝",
      "overview": "## 目标\n把博客从 Hexo 迁移到 Astro，10 月底前上线。\n\n## 完成标准\n- 旧文章全部迁移且链接不变\n- Lighthouse 性能分 > 95",
      "items": [
        { "text": "确定主题和配色", "status": "done" },
        { "text": "迁移旧文章", "status": "doing", "detail": "共 86 篇，已完成 30 篇" },
        { "text": "配置 301 跳转", "due": "2026-10-20" }
      ],
      "logs": [{ "date": "2026-09-25", "text": "完成 Astro 初始化和主题选型" }]
    }
  ],
  "tasks": [{ "title": "续费域名", "due": "2026-10-05", "priority": 1 }],
  "events": [{ "title": "博客上线评审", "date": "2026-10-28", "start": "14:00", "end": "15:00", "remind": 15, "project": "个人博客改版" }],
  "feeds": [{ "name": "Hugging Face 博客", "url": "https://huggingface.co/blog/feed.xml" }]
}
```

## 二、自定义小组件 `deskboard.widget/v1`

用一段 JSON 描述「从哪里取数据、取哪些字段、怎么显示」，看板用通用渲染器显示，不需要写代码。
适合：各类热门榜单、价格 / 汇率、天气、服务状态、任意返回 JSON 的公开接口或 RSS。

```json
{
  "format": "deskboard.widget/v1",
  "id": "hf-trending-models",
  "name": "HF 热门模型",
  "description": "Hugging Face 上近期热度最高的模型",
  "icon": "ai",
  "color": "#FF9D00",
  "source": {
    "type": "json",
    "url": "https://huggingface.co/api/models?sort=trendingScore&limit=20",
    "refreshMinutes": 60
  },
  "map": {
    "items": "",
    "title": "{{id}}",
    "subtitle": "{{pipeline_tag}}",
    "value": "{{likes|num}}",
    "link": "https://huggingface.co/{{id}}"
  },
  "display": { "type": "list", "rank": true }
}
```

### 顶层字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `format` | string | 是 | 固定为 `deskboard.widget/v1` |
| `id` | string | 是 | 唯一标识，小写字母、数字、`-`。与已安装的相同则视为更新 |
| `name` | string | 是 | 显示名称，建议 10 字以内 |
| `description` | string | 否 | 一句话说明 |
| `icon` | string | 否 | 图标名，可选：`clock` `calendar` `agenda` `tasks` `notes` `project` `ai` `news` `github` `settings` `image` `grid`。默认 `grid` |
| `color` | string | 否 | 图标底色 `#RRGGBB`，不填则跟随主题配色 |
| `source` | object | 是 | 数据来源，见下文 |
| `map` | object | 是 | 字段映射，见下文 |
| `display` | object | 否 | 显示方式，见下文 |

### `source` 数据来源

| 字段 | 类型 | 说明 |
|---|---|---|
| `type` | string | `json`：GET 一个返回 JSON 的地址；`rss`：RSS / Atom 地址 |
| `url` | string | 只支持 `https://`（本地调试可用 `http://localhost`） |
| `headers` | object | 可选，额外请求头，如 `{"Accept": "application/json"}` |
| `auth` | object | 可选，需要密钥的接口用：`{"header": "Authorization", "prefix": "Bearer ", "secret": "名称"}`。密钥由用户在创造台里填写并保存在 Windows 凭据管理器，**规范里不要写真实密钥** |
| `refreshMinutes` | number | 自动刷新间隔，默认 30，最小 5 |

`rss` 类型的每一条数据有这些字段可用：`title`、`link`、`published`（时间）、`summary`（摘要纯文本）。

### `map` 字段映射

`items` 是一个**路径**，指向列表所在位置；其余字段都是**模板**，用 `{{路径}}` 引用当前这一条的数据。

| 字段 | 说明 |
|---|---|
| `items` | 列表路径。接口直接返回数组时写 `""`；在 `data.list` 里就写 `"data.list"`。`stat` 显示方式下可以指向一个对象 |
| `title` | 标题（必填） |
| `subtitle` | 副标题，可选 |
| `value` | 右侧数值，可选 |
| `link` | 点击后打开的网址，可选 |
| `label` | 仅 `stat` 用：数值下方的说明文字 |

**路径写法**：用 `.` 访问字段、`[n]` 访问数组元素，例如 `data.items[0].name`、`rates.CNY`、`node.title`。`{{.}}` 表示当前这一条本身。

**过滤器**：在路径后加 `|名称`

| 过滤器 | 作用 | 例子 |
|---|---|---|
| `num` | 大数字缩写 | `12345` → `12.3k` |
| `fixed2` | 保留两位小数 | `7.123456` → `7.12` |
| `ago` | 时间转为“几分钟前” | ISO 时间或秒 / 毫秒时间戳 |
| `date` | 时间转为 `MM-DD HH:mm` | 同上 |
| `trim40` | 截断到 40 个字符 | 适合长描述 |
| `host` | 网址只保留域名 | `https://a.com/x` → `a.com` |

模板里可以混写文字，例如 `"value": "♥ {{likes|num}}"`、`"link": "https://www.v2ex.com/t/{{id}}"`。取不到的路径会显示为空。

### `display` 显示方式

| 字段 | 说明 |
|---|---|
| `type` | `list`（默认）：列表；`stat`：大数字，适合价格、温度、汇率 |
| `rank` | `list` 用：是否在每行前显示排名，默认 `false` |
| `limit` | 最多显示几条，默认按小组件大小自动决定 |
| `sizes` | 允许的尺寸，默认 `["s","m","l","xl"]`；`stat` 建议 `["s","m"]` |

### 示例

**V2EX 热帖（列表）**

```json
{
  "format": "deskboard.widget/v1",
  "id": "v2ex-hot",
  "name": "V2EX 热帖",
  "icon": "news",
  "source": { "type": "json", "url": "https://www.v2ex.com/api/topics/hot.json", "refreshMinutes": 30 },
  "map": { "items": "", "title": "{{title}}", "subtitle": "{{node.title}}", "value": "{{replies}} 回复", "link": "{{url}}" },
  "display": { "type": "list" }
}
```

**美元兑人民币（数字）**

```json
{
  "format": "deskboard.widget/v1",
  "id": "usd-cny",
  "name": "美元汇率",
  "icon": "ai",
  "source": { "type": "json", "url": "https://open.er-api.com/v6/latest/USD", "refreshMinutes": 360 },
  "map": { "items": "", "title": "{{rates.CNY|fixed2}}", "label": "1 USD = ? CNY", "subtitle": "更新于 {{time_last_update_unix|date}}" },
  "display": { "type": "stat", "sizes": ["s", "m"] }
}
```

**上海当前气温（数字）**

```json
{
  "format": "deskboard.widget/v1",
  "id": "weather-shanghai",
  "name": "上海天气",
  "icon": "clock",
  "source": { "type": "json", "url": "https://api.open-meteo.com/v1/forecast?latitude=31.23&longitude=121.47&current=temperature_2m&timezone=auto", "refreshMinutes": 30 },
  "map": { "items": "current", "title": "{{temperature_2m}}°C", "label": "当前气温", "subtitle": "{{time|date}}" },
  "display": { "type": "stat", "sizes": ["s", "m"] }
}
```

**某个 RSS 源（列表）**

```json
{
  "format": "deskboard.widget/v1",
  "id": "hf-papers",
  "name": "HF 每日论文",
  "icon": "notes",
  "source": { "type": "rss", "url": "https://papers.takara.ai/api/feed" },
  "map": { "items": "", "title": "{{title}}", "subtitle": "{{summary|trim40}}", "value": "{{published|ago}}", "link": "{{link}}" }
}
```

## 三、使用方式

1. 打开看板 Dock 里的「**创造台**」。
2. **导入数据**：粘贴 `deskboard.import/v1` JSON，或者粘贴任意原始材料点「AI 整理」，检查预览后导入。
3. **小组件工坊**：粘贴 `deskboard.widget/v1` JSON，或用一句话描述让 AI 生成，预览没问题后安装；之后在「添加小组件」里就能找到它。
4. **规范**：一键复制这份文档，交给任意 AI 使用。
